# UAO Connect

Red social de la UAO. 
Proyecto final de Estructuras de Datos II.

## Integrante
- Jorge Steven Correa

## Tecnologías
- React + Vite
- React Router
- SASS
- Firebase (Authentication y Firestore)

## Correr el proyecto
1. `npm install`
2. Copiar `.env.example` a `.env` y llenar las variables de Firebase
3. `npm run dev`
